# Sistema de Gestão Acadêmica

Projeto otimizado para execução no **GitHub Pages**.

## Estrutura de Arquivos
- `index.html`: Página principal
- `.nojekyll`: Arquivo para ignorar processamento do Jekyll no GitHub Pages
- `assets/css/style.css`: Estilização da aplicação
- `assets/js/app.js`: Scripts e interatividade
- `assets/img/`: Imagens e logotipos do projeto

## Como publicar no GitHub Pages
1. Suba este repositório para o GitHub.
2. Vá em **Settings** > **Pages**.
3. Em **Source**, selecione `Deploy from a branch`.
4. Selecione a branch `main` e pasta `/ (root)`.
5. Clique em **Save**.
